💡 Emacs Server & Workflow Tips

To allow the browser extension to trigger Search in Emacs (C-c d b s) or Open ebuku (C-c d b b), ensure the Emacs server is running:

;; Add to your init.el to ensure the Emacs server starts automatically: (require 'server) (unless (server-running-p) (server-start))

Or start it on-demand inside your running Emacs session with: M-x server-start RET.
